# The "Graal 4.04r2.exe" export is a packer stub

Date: 2026-11-07. Tags as in `README.md`. Nothing was run.

The Drive file named `Graal 4.04r2.exe` is a decompile of 3,706 lines and 102,537 bytes (sha256 prefix `a9102af4`). Its `entry` calls `VirtualAlloc` and `VirtualProtect`. It has no string literals and no Graal or Torque class. It is a packer stub, not `Graal4.exe` and not `GraalEngine.dll`. **[bin]**

The decompile named `Graal v4.20r8[Windows].exe` is the same file, byte for byte, including the HTML companion (CRC 4287564252). See [v4-420r8-exe.md](v4-420r8-exe.md). Neither export is a v4 client. **[bin]**

What 4.04r2 actually is stays the earlier read: a Delphi launcher, `GraalEngine.dll`, and `Graal3DEngine.dll` (near-stock TGE, with `Player` and datablocks). **[bin]** ([protocol/v4x-clients.md](../protocol/v4x-clients.md), [graal3d/torque-engine-4x.md](../graal3d/torque-engine-4x.md)). Those DLLs are not in this export. A Torque teardown of 4.04r2 still needs them.

The Windows build that this folder does contain, file version 4.2.0.8, is [engine-4208.md](engine-4208.md).
