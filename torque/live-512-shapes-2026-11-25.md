# 5.12 shapes: .3ds materials, .dts versions, .dif, .ft (2026-11-25)

Lab: the real 5.12 client (and 4.20r8 where noted) on Mesa, one shape change
per run (series 4). Behaviour only; no addresses. Lab-only assets (Marble
Blast demo) stay in the lab share. Board rows: T3D-029, T3D-032, T3D-036,
T3D-038. **[lab][cap]**

## .3ds materials and meshes (T3D-032)

- A mesh with **no material** is not drawn.
- A **colour-only** material draws its diffuse colour; a material naming a
  **missing texture** draws white.
- **Col- (collision) meshes are drawn.** A 2.8-unit collision hull showed
  instead of the cube. This corrects the earlier "collision, not drawn"
  guess.
- **No back-face culling:** both windings draw, and the two-sided flag
  changes nothing.
- **Transparency is ignored:** a 50% material drew opaque.
- **Size:** 400 objects in one file, and one mesh at the u16 cap (32,761
  vertices, 64,800 faces), both drew fine.

## .3ds texture bitmaps (5.12, GDI renderer)

One textured cube per run, its texture served under the same base name with a
different file kind or size each time, cache cleared between runs. The client
asks for the texture by its bare name (no extension) and caches it without one;
the loader goes by the file's content, so a JPG named `.png` still draws. No
case crashed or logged a bitmap error. **[lab]**

| Draws correctly | Fails silently (untextured white) |
|---|---|
| RGBA PNG 1×1, 16×16, 256×256, 1024×1024 | RGBA PNG 2048×2048 and 4096×4096 |
| non-power-of-two (256×128, 200×200) | PNG with 16 bits per channel |
| 24-bit RGB, 8-bit palette, interlaced PNG | BMP (24-bit) |
| JPG | an empty file |
| 8-bit grey (draws grey) | |
| GIF, with slight colour error from its palette | |

So the shape texture size limit lies between 1024 and 2048 pixels a side. A
truncated PNG drew the faces black (or not at all; to be checked). **[lab]**

## .dts versions (T3D-029)

A v24 octahedron with only the version word changed (so these are v24 bodies
mislabelled, not genuine old shapes):

| Version word | Result |
|---|---|
| 16 | rejected, "not supported anymore"; play continues |
| 17, 18 | hang on a black 3D view |
| 19 | crash (access violation) |
| 22 | crash (access violation) |
| 23 | loads, draws nothing |
| 24 | draws |
| 25 | rejected, "only version 24 and before" |

So the header accepts 17 to 24, but the reader then **trusts the version
word without bound-checking the body that follows**: a body that does not
match its claimed version hangs or crashes rather than being rejected
cleanly. Genuine old-version shapes were not tested here (these were all v24
bytes).

## .dts / .dif that do draw

The Marble Blast demo shapes (lab only, all v24) draw: `superJump`,
`ductfan` (with its sequences) and the gem. `training1.dif` (v44) draws. The
client also asks for `lightfalloffmono` (harmless).

## .ft text shapes (T3D-036)

A live `.ft` GameObject never draws on 5.12, across flags 0, 0x08 and 0x18
and defaultLevels 1, 2 and 6, and when malformed. The `.ft` file and its
texture both download and nothing is logged. So `.ft` is fetched but not
drawn in these cases; why is still open.

## 4.20r8

On the fuzz rows 4.20r8 matched 5.12, including the crash on a huge
`TerrainBlock` squareSize.

Under the GDI renderer 4.20r8 draws **no textures at all**. A textured `.3ds` cube stays untextured white at every
size from 1×1 to 4096 (and at 256×128), and the sky shows as a plain grey gradient instead of its
six faces. No crash in 110 s per run. Under Mesa llvmpipe it is the same: 4.20r8 downloads each texture (and saves it without an extension) but still draws the `.3ds` untextured, also with the texture planted as `.png` and without an extension. So 4.20r8 does not texture this `.3ds` at all, and its size limit can't be measured this way. **[lab]**

Cache layout differs: 4.20r8 saves downloads in subfolders named by the file's prefix
(`levels3d/images/lp/lp_white`, `lp/lp_white.3ds`, `sky/sky_…`), while 5.12 puts them flat in
`levels3d/images` (except `sky/`). A lab clearing the cache between runs must clear those
subfolders on 4.20r8. **[lab]**
