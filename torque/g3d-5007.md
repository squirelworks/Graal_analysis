# Graal3DEngine.dll 5.0.0.7

Date: 2026-11-07. Static read of the decompile in the v5 export. Nothing was run. **[bin]**

This DLL's decompile has no file-version string. The launcher beside it is file version `5.0.0.7` ([launcher-5007.md](launcher-5007.md#what-the-decompile-is)). A compile-date string is not in this decompile. **[bin]**

## Torque that is still here

Torque's core is in this DLL. String and type names that are present: `GuiCanvas` (used: `setContentControl`, `paint`, `mouseLock`, `showHint`), `GuiControl`, `SimObject`, `SimSet`, `SimGroup`, `NetConnection`, `GameConnection`, `GameObject`, `SceneObject`, `ActionMap` (`ActionMapGroup`, `GlobalActionMap`, `ActiveActionMapSet`), `TerrainBlock`, `WaterBlock`, `Camera`, `fxSunLight`, `TSShape` (`TSShapeInstance::getSequence`), `GBitmap`, `MatrixF`. **[bin]**

Display strings: `Activating the %s display device`, `OpenGL Init: Enabled Extensions`, `OpenGL Init: Disabled Extensions`, `opengl2d3d.dll`. The class names `OpenGLDevice` and `D3DDevice` are absent. `Sky` and `Sun` are absent. **[bin]**

World strings that are present: `DynamicGrass`, `DynamicGrassReplicator`, `DynamicShapeReplicator`, `fxFoliageSet`, `fxGrassSet`, `twSurfaceSet`, `GameShape`, `GameShapeDTS`, `GameShapeDIF`, `GameShapeFT`, `*.dts`. 3DS files are read (`3DS file: Collision hull %s is n…`, `3dscolor%d%d%d`). The token `GameShape3DS` is absent. **[bin]**

Absent: `ShapeBase`, `PlayerData`, `GameBase`, `.dso`, `ScriptObject` as a Torque class (the only `ScriptObject` hit is `graal_setGetGraalPlayerScriptObject`). There is no "Download Datablocks" phase string. The word `datablock` is one key a stream reader compares, next to `class`, `rotation` and `scale`. **[bin]**

## Protocol window

One routine writes `CHR_PROTOCOL` unless the value it is testing is greater than 23 and less than 25, so only 24 passes. The decompiler did not name that value. `CHR_INVALID` is also a string. `CHR_PROTOCOL_LESS`, `CHR_GAME` and "Only official Graal clients" are absent from this DLL. **[bin]**

Other Torque event names: `BigDataStartEvent`, `BigDataChunkEvent`, `RemoteCommandEvent`, `ConnectionMessageEvent`, `GhostAlwaysObjectEvent`, `NetStringEvent`, `RequestReloadEvent`. Handshake logs include `Sending Connect challenge Reques…`, `Got Connect challenge Response`, `Sending Connect Request`, `Got Connect Request`, `Issuing Disconnect packet.` **[bin]**

## Graal types it uses

`TAdventure`, `TGraalVar`, `TScriptExecutionSpace` and `TShowImg` appear as placeholder types this DLL calls into (`TAdventure` construct and destroy, `TScriptExecutionSpace::setClasses`, `invokeGraalEvent` on a `TGraalVar`). They are defined in `GraalEngine.dll` ([engine-5007.md](engine-5007.md#graals-game)). `GuiGraal3DCtrl` is a string. `TGraalAni` is present as a type name. **[bin]**

## graal_set calls

Export comments name `loadGraal3DEngine`, `runGraal3DEngine`, `endGraal3DEngine` and `resizeGraal3DWindow`. `toggleGraal3DFullScreen` is a named function in the same DLL and this listing has no export comment on it. **[bin]**

A startup routine calls 78 `graal_set*` functions, passing this DLL's own routines, then calls `graal_engineInitialize`. That is the host side: it registers draw and 3D callbacks, it does not define the setters. The 3D-only names and the shared draw set are in [engine-5007.md](engine-5007.md#who-calls-the-setters). **[bin]**

After registration the log string `Graal3D has been activated!` is in the DLL. **[bin]**
