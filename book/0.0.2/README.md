# Graal Analysis 0.0.2

A reading of the notes, in five chapters. Chiaki tags `v0.0.2`.
The 0.0.1 document PDFs stay in `release/0.0.1/`.

The notes viewer is already on `main`. From a checkout of this repository:

```
python3 tools/navigator/navigator.py
```

It listens on the loopback address, port 8765. No virtualenv is required.
