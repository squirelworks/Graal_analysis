# GS2 in unpacked Windows 6.1.1.3

Date: 2026-11-07. Static read of the unpacked 6.1.1.3 listing, compared with the unpacked 6.0.3.7 listing and with `protocol/gs2-client-only-opcodes.md`. Nothing was run. Tags: **[bin]** the two listings · **[doc]** the Preagonal summary already in that opcode note.

The packed 6.113 listing has no script switch (`protocol/gs2-6113.md`). This page is the switch in the unpacked image.

## Load path and the `.code` cache

A file whose name ends in `.code` is read as a script cache. A buffer shorter than eight bytes is rejected. A longer buffer is compared with the magic `GRESCR01`. The CRC32 is taken over the bytes after those eight. A cache flag other than 1 returns an empty script. When the magic matches, the container is the one the walker runs. **[bin]**

The segment walker and the operand widths were not re-derived here. They stay the 6.00 description in `protocol/gs2-client-vm.md`. **[bin]**

## Opcode range

The dispatcher has 152 cases. The lowest is 11 and the highest is 242. There is no case above 242. **[bin]**

Present, and named by the client-only note as opcodes the Preagonal compiler does not emit: 43, 45, 46, 47, 54, 66, 67, 104 (`compare`), 121, 190, every case from 201 through 233, and 234 through 242. **[bin][doc]** (`protocol/gs2-client-only-opcodes.md#which-image-dispatches-it`)

Absent: 48, 49, and 200. Case 200 is the one number inside 200–242 that this switch does not have. The effects of 234–242 were not re-read; the cases are present. **[bin]**

Unpacked 6.0.3.7's dispatcher has the same 152 cases, the same minimum and maximum, and the same absence of 48, 49 and 200. No case is in one image and not the other. **[bin]**

## Builtins

A complete builtin-name table was not extracted. The script methods that load class, weapon and gani scripts are the `onSendWantClassScript`, `onSendWantWeaponScript` and `onSendWantGaniScript` events. Which builtin index calls which of those: not found. **[bin]**

## Against Preagonal

Preagonal's compiler enum has no member for the opcodes its note lists as client-only, and no member at 200 or above. This image runs 54, 121, 104, 190, 201–242 and the earlier client-only cases in the table above. It does not run 48 or 49, which that note records only for 5.0.0.7. **[doc][bin]** (`npc-library/preagonal-gs2.md`, `protocol/gs2-client-only-opcodes.md`)
