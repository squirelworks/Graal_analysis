.SH NAME
graal \- official client tree kept under artifacts/graal
.SH SYNOPSIS
artifacts/graal/
.SH DESCRIPTION
This is a Graal online client directory as shipped by Linux
Cyberjoueur (manager Stephane Portha, technical director Stefan Knorr),
not the SDL fork.
.B readme.txt
is the release note: HawkVoice under the LGPL, joystick and
dinput.dll troubleshooting, and the classic controls.
.PP
The SDL fork in
.BR 2dadventureclient (7)
does not load this folder.
It does use the same level text format and the same 4096 tile ids.

.I levels/tiledefs/tiledefsOffline.txt
is one tiledef line:
.PP

.PP
That is the
.B addtiledef
record from
.IR newfeatures2001.txt :
image, level-name prefix, type, optional x, y.
Type 0 is the old Graal order
.RB ( pics1.png ).
Type 1 is the new order.
.B addtiledef2
paints a rectangle on top of the base sheet, which is how a single
chair or lamp gets replaced without a new 4096-tile image.

.SS Everything else at the top
.B maps/
holds
.IR bigmap.txt , minimap.txt , newmainmap.txt ,
the matching pngs, and
.IR offlinetutorial.gmap .
.B sounds/
is 104 wav files.
.B languages/
is nine
.I language*.txt
files: Deutsch, English, Espanol, Francais, Italiano, Nederlands,
Norsk, Portugues, Svenska.
.B tileobjects/
is the editor stamp library; see
.BR tileobjects (7).
.PP
.B generators/
contains the dungeon, level, and terrain generators
.RI ( TerrainGenerator.exe ,
.IR docu_terraingenerator.txt ,
and the dungeon generator's loose levels and pngs).
.B RC2/
is a remote-control bundle: 64 dll, 69 png, one exe.
.B weblevels/
and
.B pms/
are empty.
.PP
Changelogs, largest first:
.IR newfeatures2001.txt " (75923, the useful one),"
.IR newfeatures2002.txt ,
.IR newfeatures141.txt ,
.IR newfeatures2005.txt ,
.IR newfeatures2003.txt ,
.IR newfeatures2004.txt .
.I newfeatures2001.txt
is where GLEVNW01, the base64 tile pair, addtiledef, setshape2's
type list, and the tileobjects folder are specified.
.I commands.rtf
is the long command list.
.I npcprogramming.doc
is the NPC script manual.
.I graalconfig.txt
is a saved options file (keys, volumes, 1024x768, language English,
font Tempus Sans ITC).
.I new1.nw
is a sample text level.
.I headsconfig.txt
lists heads.
.I FILENAMECACHE.txt
is a filename cache, not a catalog you should edit by hand.
.SS Controls named in readme.txt
F1 options, F4 editor, F5 load level, F6 debug, F7 player list,
F8 server list, Escape ends the game.
Player 1 moves with arrows or IJKL; item D, attack S or space,
action A, map M, weapon list Q.
Those are Graal.exe keys.
The SDL fork only reads the arrow keys for walking.
