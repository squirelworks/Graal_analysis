# Graal 1.39 (Aug 2000 build): protocol summary (derived)

Checked against `versions-133-139.md`, `version-tokens.md` and the 1.39 entry in `v133-v139.toml`.

## Login
- Host `www.graalonline.com`, port `14900` (strings in the binary, port parsed at connect time). No listserver step.
- Socket: TCP_NODELAY-style option set, non-blocking after connect.
- Login message is packet id 0 with payload: token `GNW07080` (built one character at a time), then one byte (account length + 32) and the account name, then one byte (password length + 32) and the password. Default account string is "guest". **Same as the existing note.**
- Level warp style join with id 0 and id 30 packets exist for offline `.code` weblevels in the join routine.

## Framing and encryption
- Each message: id byte (id+32), payload, newline. A payload that contains a newline is silently dropped by the send helper (new detail, also true in 2.05).
- Queue is flushed when it would pass 4095 bytes. Each flush is zlib-compressed behind a 2-byte big-endian length. Sent to the socket in slices of 256 bytes.
- If more than 0x3ffff bytes (about 256 KiB) of compressed output are pending, the client closes the connection.
- No cipher and no type byte (generation 2). **Matches** the notes.

## Packet ids
- Client to server ids passed as constants: 0 to 5, 7 to 24, 26 to 33, 80, 81. The existing list also has 6 (sent from a register-based site) and has no 25. **Matches.**
- Server to client dispatch handles ids 0 to 41, 43, 75, 100 (wire bytes 32 to 73, 75, 107, 132). **Matches** the existing `plo_known` list. Id 100 (raw data) and 75 are in the list.

## Features seen in the binary
- DirectDraw and DirectSound through a Delphi DX component set, joystick and force-feedback classes, MNG and GIF animation, DDE classes (library code).
- Emoticon lookup by `emoticon_<letter>` file name with png/mng/gif extensions already exists (same routine as 2.05). Consistent with the existing "emoticons from 1.38".
- Sound files, shield/sword gif sets 1 to 4, `levels\webgifs\`, `levels\recordpos.txt`, `weblevels\`.

## Not re-verified
The F7 popup items for 1.39 (menu strings are built character by character), death handler, sword hit box.
