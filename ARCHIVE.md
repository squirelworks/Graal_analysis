# Archive note — Graal Analysis project

Date: 2026-10-28

The analysis project that produced these notes is being decommissioned.

## What is archived

A complete zip of the local analysis corpus (`Graal Client Analysis.zip`, ≈102 MB) has been placed in Google Drive under `[Grok/[Projects/`.

It contains:
- Dated snapshots (2026-10-01, 2026-10-02, 2026-10-04)
- Unixsane incremental passes
- Phoenix2 / Phoenix3 architecture and ledger
- Lumiere, Ash, Lantern notes
- Sign decoder, tiledef masks and plugin
- Seihai drop-in packages (formats, protocols, version token, full v2.05 corpus)
- The printable Graal v2.05 Client Reference Manual

## Boundary (unchanged)

Raw decompiles, function addresses, and binary dumps stay out of this repository. The notes here remain cleaned observations derived from public sources, captures, and format documentation.

## Prior attempts (summary)

The analysis corpus captured successive passes against Graal.exe v2.05 rev2 and earlier clients:

- Early field notes and architecture collapse (Phoenix)
- GS1 dispatch plating and row table
- Session / list / world protocol framing and version-token construction
- Tile-walk rules, sign alphabets, config and drop-files behaviour
- Offline training levels versus session levels
- Cross-version builds, list-host behaviour, and world rejections

Those passes are preserved in the Drive zip. The cleaned notes in this repository are the shareable subset.

## Next

Seihai is the active client project. Further protocol, format, and testing work continues there. This repository remains a reference for the cleaned observations.
