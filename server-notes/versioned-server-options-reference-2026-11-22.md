## Reading the comparison

Documented value domains, explicit defaults, examples and source fallbacks are
separate claims. A Boolean pair specifies a domain; a printed assignment alone
does not establish a default. Composite value templates do not introduce extra
keys. Similar language names do not establish aliases. **[doc]**

Source navigation classified the 99 concrete spellings into 41 cache declarations,
30 direct-reader entries, six dynamically constructed spawn readers and 22 keys
not located by the bounded pinned literal search. These categories organize the
reference; they are not a runtime acceptance census. Generic setting storage and
script lookup prevent a missing literal from proving rejection or global absence.
Cache declaration, registration, selected reads and executed effects are different
levels of evidence. **[srv]**

The table below uses original-prose descriptions of selected source paths. Prior
family notes retain their narrower consumer and failure-path analysis. No server,
client, live reload, original implementation or macOS runtime was executed for
this comparison. G067's historical and original/runtime questions remain open.
