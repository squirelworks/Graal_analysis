## Lion guest run (6.015)

Host: the Linux VM host. Guest: Lion 10.7.5 research overlay
(`NET=none`, one Mac VM only). Client staged on `GRAALIN` as `Graal.app`, then
`ditto` into the guest home under `Graal/v6.015/`.

| Step | Result |
| --- | --- |
| First `open` after `ditto` | Launch Services error `-10810`; main binary mode was non-executable |
| `chmod +x` on `Contents/MacOS/Graal`, then `open` | App becomes frontmost; menu bar shows **Graal** |
| Window | Title **Graal**; content area stays **white** |
| Process | `Graal` stays up under LaunchServices (`-psn_…`); no crash dialog |
| Network | Offline (`NET=none`); no login attempt |

The white content area matches the earlier Lion note for Mac 6.11r1 (std VGA,
no guest OpenGL acceleration). This run extends that observation to **6.015**
but still does **not** prove a first rendered game frame, playable login, or
level draw. **[lab]**

ISO / `ditto` staging on this guest can drop the executable bit; live launches
must restore it before `open`. **[lab]**
