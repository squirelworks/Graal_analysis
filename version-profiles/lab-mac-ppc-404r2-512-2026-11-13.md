# Lab run: the real Mac PowerPC 4.04r2 and 5.12 clients on Mac OS X 10.4

Date: 2026-11-13. Settles the "4.04r2 and 5.12 live" item of Graal_analysis #399. Both builds
ran **unchanged** on Mac OS X 10.4 (Tiger) in an emulated PowerPC machine (qemu), offline,
against a GServer-v2-derived lab server (squirelworks/seihai-gserver-v2 with seihai-gs2lib) on a
host-only network. Each logged in, took the 178 warp, loaded the level and walked **[lab][cap]**.
The profiles are published in squirelworks/seihai-core PR #36 (release 0.0.22) and the version
constants in squirelworks/seihai-gs2lib PR #17 **[doc]**. Earlier Mac lab:
[lab-mac-tiger-2026-10-31.md](lab-mac-tiger-2026-10-31.md) (4.20r6 and 3.153).

Captures, the unmasked login bytes and screenshots stay owner-held; the password is never
published.

## Tokens and login line

| Build | Token | Login comma list | Tag |
| --- | --- | --- | --- |
| 4.04r2 Mac | `G3D18026` | `mac`, then two machine hashes | [cap] |
| 5.12 Mac | `G3D15097` | `mac`, two machine hashes, then the quoted Darwin kernel string as a fifth field | [cap] |

Their own props after login are `OSTYPE` `mac` and `TEXTCODEPAGE` 0 **[cap]**. The Windows tokens
encode their build dates (for example `G3D14097` is 14 September 2007, → [../client-internals/version-tokens.md](../client-internals/version-tokens.md));
the Mac tokens differ from the Windows ones of the same version.

## Framing

- Both Mac builds use 5.12's **round-down** gen-5 cipher step (the step count per frame is
  rounded down, not up) **[cap]**.
- Only the Windows 5.12 compresses every frame; neither Mac build does **[cap]**.
- The Mac 4.20r6 keeps the round-up step until its own frame cipher is read **[inf]**.

## What the server needed

- The lab server's version table needed separate constants for the Mac 4.04r2, 4.20r6 and 5.12
  so it picks the Mac cipher step (seihai-gs2lib #17) **[doc]**.
- GS1 weapon text had to be sent with `\xa7` line breaks; sent as plain lines it split into
  separate ids 73, 84 and 93 on these clients **[cap]**.
- The Mac 4.20r6 needs `PLO_PING` from the server **[cap]**.

## Other observations

- Neither build starts a helper process. The "context helper" in the static reading is the
  AGL pixel-format path, which fails without hardware OpenGL in the emulated machine **[lab]**.
- 5.12 Mac draws a black level on a modern lab world even with the render shim. Cause: the
  bundle has no `pics1.png`, and the lab server refuses it as "too large for client version"
  because the Mac tokens are missing from its version table (an unknown token ranks oldest,
  and the oldest clients get no file over 64 KB). See the
  [harness run](../live-runs/client-harness-2026-11-13/README.md#mac-powerpc-items-399) **[lab]**.
- The lab world lacked `state.png` and `wbowi1.png` **[lab]**.
