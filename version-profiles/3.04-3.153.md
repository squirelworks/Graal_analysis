# Version profiles: 3.04 (Linux) and 3.153 (Mac OS X)

Date: 2026-10-30

This note is the per-version profile for the two readable Graal 3.x clients, in the same shape as `2.22-2.31.md`. The machine-readable table is `3.04-3.153.toml`. Background on the clients themselves (Torque engine, licence file, listserver, file formats) is in `protocol/v3x-clients.md`.

Sources: the 3.04 Linux client (unpacked from UPX) and the 3.153 Mac OS X client, read statically, plus the compiled TorqueScript and prefs shipped with them. 3.04 was then run against GServer-v2 in the lab (`lab-304-linux-2026-10-30.md`). Tags: **[bin]** client binary · **[file]** shipped data · **[cap]** lab run (3.04 only) · **[inf]** inferred.

## Builds

| Label | Platform | Token | Windows twin |
|---|---|---|---|
| 3.04 (rev 1, 3.041) | Linux i386 | `G3D03014` | 2.22 (`GNW03014`) |
| 3.153 | Mac OS X PPC | `G3D28015` | 2.31 (`GNW28015`) |

The tokens share date stamps with the Windows builds, and the wire protocol matches: gen-5 login (type 5, key byte, token, plain account and password), the same LCG cipher, framing, compression thresholds and XOR caps. **[bin]**

## Login and listserver

- Listserver: id 7 `G3D30123newmain` and id 1 (account, password), sent together in one plain zlib frame; the reply is gen 5 **[cap]**. The host list comes from the signed `license/license.graal`, which names `listserver.graalonline.com:14922`. For Seihai the profile uses `listserver.graal.in:14922` (supported) with port status **assumed**: no G3D token has been tried against the public listserver. **[bin][file]**
- The game login frame also carries 37 (language) and 34 for `bigmap.txt` and `minimap.txt`. The client **never sends 39** (tampercheck) and sends nothing periodic over TCP; its 5.1 s message (2.31's TCP 24) goes to other players over UDP. Then it starts UDP unless `$pref::Graal::noudp` is set, and requests its own images with 23 and 34, at most five at a time. **[bin][cap]**
- First props sent: 0, 18, 31, 33, 52, 75 (`linux`) and 76 (1250 in the lab). **[cap]**
- Server names carry a category prefix: `P ` Gold, `3 ` 3D, `H ` Hosted, `U ` hidden, none Classic. **[bin]**

## Player-visible features

- **3.04** start window: Nick, Language, Options, Tutorial, Account, Password, Get Account, Start. Server list tabs Graal Gold, Classic, Graal 3D and Hosted, with a direct-connect field. Options tabs Graphics, Audio, General. Player list, PMs, a profile window, and an offline mode that loads a local level. No in-client editor. **[file]**
- **GS1** (3.04): 496 registered names. Every 2.05 command is present except `putobject`, `setbackpal`, `setbody`, `setbacktile`, `drawovertrees` and `setbacktile2`. 3.153 was not counted. **[bin]**
- **3.153** adds a 3D mode (Torque `GameConnection` on port 28000 with missions and terrain), snow and xmas themes, the RC file browser and script uploads, and server-side class scripts (131–134). The shipped prefs turn UDP off (`noudp = 1`, fixed port 14899). **[file][bin]**

## Observed behaviour (3.04)

Walk speed 10 tiles per second, `push` after about 0.9 s against a wall, a 0.25 s `sword` gani, dropped items removed by the client after 8.3 s, no 11 when a bush is thrown, chat drawn as white text with a blue shadow and no bubble, and the 2.05 UDP channel unchanged (movement, chat, trigger action, a 5.1 s keepalive). Details and timings are in `lab-304-linux-2026-10-30.md`. **[cap]**
