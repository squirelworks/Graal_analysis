# Version profiles: 3.04 (Linux) and 3.153 (Mac OS X)

Date: 2026-10-30

This note is the per-version profile for the two readable Graal 3.x clients, in the same shape as `2.22-2.31.md`. The machine-readable table is `3.04-3.153.toml`. Background on the clients themselves (Torque engine, licence file, listserver, file formats) is in `protocol/v3x-clients.md`.

Sources: the 3.04 Linux client (unpacked from UPX) and the 3.153 Mac OS X client, read statically, plus the compiled TorqueScript and prefs shipped with them. Neither was run, so there is no capture evidence. Tags: **[bin]** client binary · **[file]** shipped data · **[inf]** inferred.

## Builds

| Label | Platform | Token | Windows twin |
|---|---|---|---|
| 3.04 (rev 1, 3.041) | Linux i386 | `G3D03014` | 2.22 (`GNW03014`) |
| 3.153 | Mac OS X PPC | `G3D28015` | 2.31 (`GNW28015`) |

The tokens share date stamps with the Windows builds, and the wire protocol matches: gen-5 login (type 5, key byte, token, plain account and password), the same LCG cipher, framing, compression thresholds and XOR caps. **[bin]**

## Login and listserver

- Listserver: id 7 `G3D30123newmain`, then id 1 account and password. The host list comes from the signed `license/license.graal`, which names `listserver.graalonline.com:14922`. For Seihai the profile uses `listserver.graal.in:14922` (supported) with port status **assumed**: no G3D token has been tried against the public listserver. **[bin][file]**
- After the game login the client sends 37 (language) and **never 39** (tampercheck). Then it starts UDP unless `$pref::Graal::noudp` is set, and requests its own images with 23 and 34, at most five at a time. **[bin]**
- Server names carry a category prefix: `P ` Gold, `3 ` 3D, `H ` Hosted, `U ` hidden, none Classic. **[bin]**

3.04 handles 79 ids, 3.153 handles 88; the table is in `protocol/v3x-clients.md`. Against 2.22, 3.04 lacks 170, 177, 182 and 183 and adds 84, 101 and 102. **[bin]**

## Player-visible features

- **3.04** start window: Nick, Language, Options, Tutorial, Account, Password, Get Account, Start. Server list tabs Graal Gold, Classic, Graal 3D and Hosted, with a direct-connect field. Options tabs Graphics, Audio, General. Player list, PMs, a profile window, and an offline mode that loads a local level. No in-client editor. **[file]**
- **GS1** (3.04): 496 registered names. Every 2.05 command is present except `putobject`, `setbackpal`, `setbody`, `setbacktile`, `drawovertrees` and `setbacktile2`. 3.153 was not counted. **[bin]**
- **3.153** adds a 3D mode (Torque `GameConnection` on port 28000 with missions and terrain), snow and xmas themes, the RC file browser and script uploads, and server-side class scripts (131–134). The shipped prefs turn UDP off (`noudp = 1`, fixed port 14899). **[file][bin]**

## Open

- Run the 3.04 Linux client in the lab against GServer-v2 to confirm the login, the absence of 39, and the post-login sends. This is the cheapest way to turn the [bin] values into [cap].
- Try the `G3D30123` listserver login against the public listserver to settle the port status. This is an outward action and has not been done.
- A clean copy of the 3.151 Linux installer would give a third data point between the two.
