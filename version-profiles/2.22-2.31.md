# Version profiles: 2.22, 2.3 and 2.31

Date: 2026-10-22

This note covers what a client has to do to *be* 2.22, 2.3 or 2.31: what it sends and understands on the wire, and how it looks and behaves for the player. The machine-readable table is `2.22-2.31.toml`.

Sources:
- `Graal_222.exe` and `Graal_231.exe` from the Graal Reborn 2.2.2.0 folder, read statically. That covers form resources, embedded images, strings, the GS1 symbol table, and the send and receive paths.
- The seihai-lab captures (2.22 only).
- GServer-v2 source.
- The release notes shipped in the same folder.

No 2.3 executable was uploaded, so every 2.3 value is inferred.

Tags: **[bin]** client binary · **[cap]** lab capture · **[srv]** GServer-v2 · **[doc]** release notes · **[inf]** inferred.

## Builds in this range

| Label | FileVersion | Token | Binary | GServer-v2 default `allowedversions.txt` |
|---|---|---|---|---|
| 2.22 | 2.2.2.0 | `GNW03014` | yes | enabled |
| 2.3 | 2.3.0.0 | `GNW14015` | **none** | commented out |
| 2.31 | 2.3.1.0 | `GNW28015` | yes | commented out |

A lab server needs `GNW14015` and `GNW28015` uncommented before it will let 2.3 or 2.31 in. **[srv]**

Caveat on the binaries: the Reborn folder's `Graal_222.exe` has a 2009 file date and `Graal_231.exe` a 2007 one. The 2.17 build in the same folder is rebranded "Eradia Online", so a community edit of the other two cannot be ruled out. Any edits would most likely be to text and server-list strings, not to the protocol code. **[bin][inf]**

## Wire protocol

The three builds share the gen-5 profile already written up in `protocol/client-versions.md` and `protocol/codec-and-framing.md`:
- Login type 5, a key byte, the token, the account and the password.
- The login frame is zlib with no compression byte. Every later frame carries a compression byte: 2 below 0x30 bytes (4 if zlib is shorter), 4 below 0x1000, and 6 (bz2) from there.
- XOR limits are 12 dwords for type 2 and 4 for types 4 and 6.
- Listserver id 7 carries `GNW30123newmain`, with hosts from `arrays2.dat`.

**2.31's send path is the same code as 2.22's**: same size thresholds, XOR limits, and 0x40000 queue cap. **[bin]**

| | 2.22 | 2.3 | 2.31 |
|---|---|---|---|
| Server → client ids handled | 80 | as 2.31 [inf] | 81: drops 44 `HASNPCSERVER`, adds 84 `LARGEFILESIZE` and 189 `MOVE2` **[bin]** |
| Client → server ids sent | 0–24, 26–30, 32–35, 37–41, 43, 44, 80 | as 2.31 [inf] | 2.22 minus 21 `PUTNPC`, plus 46 `ENTERLEVEL` **[bin]** |
| Highest PLPROP / NPCPROP parsed | 74 / 73 | as 2.31 [inf] | 80 / 77 (X2, Y2, Z2) **[bin]** |
| Precise positions | no | yes **[srv][doc]** | yes **[srv][bin]** |
| After login | 37, then 39 (10 bytes) | same | same **[bin]** |

Notes on the table:
- **Client → server set.** It was read from the call sites of the client's send helper. Id 44 (`PROCESSLIST`) was also seen in the 2.22 capture, sent as the reply to server id 182. Ids 36, 42 and 45 are not matched to a call site, so treat the set as a floor, not a complete list. **[bin][cap]**
- **Tampercheck (39).** The same 10 bytes were sent in two separate 2.22 lab sessions, so they behave like a per-build constant. Replaying the build's value is enough to pass. **[cap]** What the value hashes is still not traced.
- **2.22 login sequence in the lab.** The client sent 37 `English`, then 39, then 34 `UPDATEFILE` for its default images (sword, shield, body, bomb), 23 `WANTFILE`, and 2 `PLAYERPROPS`. It answered the server's 182 with 44. The `gr.x` / `gr.y` flag sets in the capture come from the server's movement NPC, not from the client. **[cap]**
- **Zlib fix NPC.** GServer-v2 sends a `-gr_zlib_fix` weapon to every client from 2.21 to 2.31. It pads chat text made of long runs of one or two repeated characters. This is a server-side workaround for a client compression bug, so a faithful 2.22–2.31 client should keep that bug or at least tolerate the padding. **[srv][inf]**
- **2.31 and `setmap`.** 2.31 does not request the map file after `setmap`, so GServer-v2 pushes every BIGMAP file at login for 2.31. **[srv]** It does not do this for 2.3, which suggests 2.3 still asked for the file. **[inf]**
- **Precise movement.** From 2.3, GServer-v2 puts X2/Y2 before X/Y in other-player props and stops its `gr.x` / `gr.y` / `gr.z` movement-flag workaround. **[srv]**
- **UDP.** Present in both builds, with the `noudp` and `fixedudpport` keys and the "Don't use UDP for data packages" option. `noudp` defaults to on. **[bin]**

## What the player sees

### Start window and server list

| | 2.22 | 2.31 |
|---|---|---|
| Login and server-list backdrops | the "GraalOnline" banners (samurai house, then the character line-up) | **identical images** **[bin]** |
| Start buttons | Start Online · **Training** · Options | Start Online · **Editor** · Options. Editor launches `GraalEditor.exe` **[bin][doc]** |
| Server-list tabs | Gold · Silver · Bronze **[bin]**, possibly a Reborn edit | Graal Gold · **Graal 3D** · Classic · Hosted. A 3D server shows "You need to download Graal3D…" or starts `Graal3.exe` **[bin][doc]** |
| `graal://` and `graal3://` links | no | registered at start-up. A link sends `serverstartparams` to the server's Control-NPC **[bin][doc]** |

For comparison, 2.17's tabs are Graal Gold · Classic · Hosted, and its start buttons are the same as 2.22's. **[bin]**

### In-game windows and keys

- **The editor is gone from the 2.31 client.** 2.22 still carries the full level editor:
  - the toolbar (New, Open, Save, Cut, Copy, Paste, warp field, links, signs, flags, Export Tiles Array, Play)
  - the tile and object panels and the "Show blocking tiles / foreground / terrain grid / Hide npcs" checkboxes
  - the dialogs for chests, baddies, NPCs, signs, links, flags, characters, object names and the tile array
  - the F6 script debugger

  2.31 has none of these forms (18 forms instead of 29). **[bin]**
- **The F1 help window** still lists Edit Level (F4), Load Level (F5) and Debugger (F6) in 2.31's form resource. The 2.31 notes say the unused buttons were removed, so they are presumably hidden at run time. **[bin][doc][inf]**
- **Options → General**: 2.22 has "Save downloaded images (to \levels\webgifs)". 2.31 replaces that checkbox with "Use filename cache (don't scan folders each startup)", config key `cachefilenames`, backed by `FILENAMECACHE.txt`. Every other tab is unchanged: Video, Audio (midi / mod-mp3 / radio / voice / sfx), Microphone (GSM / LPC / LPC-10 voice chat), Controls (joystick, DirectInput, Change keys), and the player-list options. **[bin]**
- **Key layout**: the Change Controls form is identical in the two builds. 2.31 fixes the saving and loading of the key configuration. **[bin][doc]**
- **HUD**: no difference in the shipped images or the HUD image file names (`state.png`, `letters.png`, `sprites.png`, and so on). The two status icons `ss_arrow.png` and `ss_bomb.png` are no longer referenced in 2.31, and neither are `graalmap.png`, `headsconfig.txt`, `loadgmaps.txt`, `recordpos.txt` or `shield1.gif`. All of these belong to offline or editor play. **[bin][inf]**

### Game behaviour

| | 2.22 | 2.3 / 2.31 |
|---|---|---|
| Classic client-side mode (client applies NPC props itself when the server has no NPC server) | yes, honours `HASNPCSERVER` | removed **[bin][doc]** |
| Smooth positions | half-tile X/Y | full-precision X2/Y2/Z2 for players and NPCs **[bin][srv]** |
| NPCs crossing gmap level borders | buggy | fixed in 2.31 **[doc]** |
| Float-to-string in scripts | buggy | fixed in 2.31 (`#v` prints integers with more than 6 digits) **[doc]** |
| CPU use | about 99 % (busy timer) | new timer **[doc]** |
| Object lookup | linear | B-tree. Huge ganis are no longer culled early **[doc]** |
| Local editor flags (`local.`, `this.-`, `gotheart_`) | present | gone with the editor **[bin]** |

### GS1 script differences (from the client's symbol table) **[bin]**

| Change | 2.17 → 2.22 | 2.22 → 2.31 |
|---|---|---|
| Added | `gravity`; `textwidth(zoom,font,style,text)`; `textheight(zoom,font,style)`; `isthisflagset` and `isplayerflagset` (replacing `isflagset`); one new `#` message code with a string argument (`#R`) | `timevar2`; `downloadsize`; `onwall2(x,y,w,h)`; `onwater2(x,y,w,h)` |
| Removed | `isflagset` | none (the command list is unchanged) |

`downloadsize` is announced in the 2.22 notes, but it is only in 2.31's symbol table, which fits the 2.3 note "is correctly giving the size". A 2.22 profile should treat it as undefined (0). **[bin][doc][inf]**

## Using this in Seihai

The `features` block in the TOML gives one switch per difference above. The three that change the most for the player:

1. `editor_in_client` (2.22 only): F4, F5 and F6, plus the Training button.
2. `serverlist_tabs`, `graal3d_tab` and `url_protocols` (start window).
3. `precise_move` (2.3+), with the matching PLPROP 78–80 and NPCPROP 77 parsing.
