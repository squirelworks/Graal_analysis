# Graal Analysis

Cleaned notes on Graal formats, protocol, NPC scripting, and level design. No decompile material.

## Contents

- `npc-library/` — 3,187 unique NPC scripts scraped from GR-V1 `.graal` levels, plus tile-neighbor patterns.
- `formats/` — GLEVNW01, GANI, GRMAP001, tiletypes, board and system notes.
- `protocol/` — packet layouts, login/walk framing, version tokens, capture notes.
- `client-internals/` — version-id map, offline-play notes, Zelda Online 1998 precursor analysis.

## Boundary

Raw decompiles stay out of this repository. These notes are derived from public server sources, observed packet shapes, and format documentation.
