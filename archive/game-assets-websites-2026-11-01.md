# Website archives left unread (2026-11-01)

The Game Assets inventory (`archive/game-assets-2026-11-01.md`) named eleven
website archives and stopped at the filename. This note is a static read of
those archives from the same Drive folder (`/[Grok/Graal/Game Assets`,
Websites). Nothing from them is committed: no HTML, no SQL, no images, no
executables. Host names that appear inside pages, shortcuts, or saved login
forms are left out. Account rows, mail, session ids, and password material
in the SQL dump were not copied.

Executables in the Dragon, construction, and NPC archives were not run.

## Old community forums

An HTTrack mirror dated 10 March 2019 (about 52 MB, about 5,800 HTML pages).
The copier cache (`hts-cache`, a log, a cookie file) sits beside the site.
The cookie file was not opened. Saved pages carry session ids in their query
strings; those ids are not repeated here.

The board is Simple Machines Forum with a green theme. The index, as saved
that day, shows 1,889 posts in 257 topics by 135 members. The newest post
named on the index is 8 November 2018. Most last-post dates on that page are
in 2018.

Two categories:

| Graal Classic | Updates and Announcements; Classic Main Forum; Bugs and Suggestions; Events; Guilds |
| General Discussion | Hello and Goodbyes; General Graal Discussion; Non Graal Related |

## Dragon site

The outer archive (about 18 MB, labelled 2014–2017) holds two inner RARs
with the same 263 names: one labelled 14 May 2014, one labelled 2 September
2017. They are the same FrontPage site, not a separate server tree.

Page dates inside are 23 April 2014. The front door says the site was made
on 9 August 2002. A news page is dated 12 November 2002. The frame set is
titled as a Dragon Tri-Jer site "for all your Graal needs".

Sections: news, tutorials (basic NPC scripting, house NPCs), a help page
that glosses staff abbreviations (police, NPC team, and the like), downloads,
NPC downloads, server guides, links, a comment form, staff list, and staff
signup. The download folder holds installers and zips for remote control,
the shop, gif2mng, a level generator, a level viewer, old and new setup
programs, and a Game Boy demo, plus one-line blurbs. Those programs were
not run. NPC downloads named on the page are small (jump rope, bat form,
fake death, level generator). Server guides are a long list of worlds;
almost every slot says the guide still needs writing. Doomsday is the one
with a weapon and system list (capture the flag, hats, outfits, stats, and
similar). A hangman popup is included. One text file is a short beginner
trainer note and another is a list of client attribute lines; neither is
copied. A comment in the guide page contains an email address; it is not
copied. Staff named on the list are Agret, Daddypuff, Ryo-Ohki, and Albino
Monkey.

## 2023 construction site

About 5.7 MB, folder dated 20 March 2023. The page files inside are dated
17 September 2019. The bundled source zip is dated 28 December 2014, and
its changelog dates 0.2.1–0.2.3 to March–August 2010.

The single HTML page is a Gonstruct site: introduction, screenshots,
changelog, and download. The introduction says regular work had already
stopped. The download offers a Windows setup named 0.2.3 (not run), a
MacPorts note, and `graal-gonstruct-master.zip`. That zip is a C++/CMake
level editor (GTK, a level-editor target, toolbar icons for links, NPCs,
signs, and tilesets). The changelog's 0.2.3 lines are crash fixes for new
NPCs and for saving transparent tiles. 0.2.2 adds editing of existing
gmaps. The readme calls the program an unofficial level editor; the host
it names is omitted.

## Kingdoms library

About 4.8 MB. The archive name spans 1998–2006. The footer on the library
pages is 2006 and credits Björn. One index file is dated 17 March 2007;
most of the HTML was saved 20 January 2014. 946 PNGs sit beside 78 HTML
pages, 3 PHP pages, two stylesheets, and a tooltip script. The images were
not opened one by one.

The front title is "Server: Graal Kingdoms - Item LIB", with a note that
the site was tested in Firefox. The menu is Home, Kingdoms, Maps,
Tutorials, Gods, Commands, and a LIB menu: Armour, Food, Furniture, Magic,
Misc, Weapons, Special. A furniture page splits into beds, carpets, chairs,
and other. Item rows show a name, a weight, and "last edit by Björn" with
an empty date. A kingdoms page describes Samurai as a feudal-Japan area
with paper walls and pagoda roofs. Map pages are click-to-enlarge
screenshot maps: Dustari, Forest, Pirates, Samurai, Zormite, Udung, Events,
and a main map. Tooltips on those maps are short quest hints (bring a
wizard a heart or a skin, a pirate shipyard, a geologist). A corner widget
says how many players were online and offers login, password, and register.
No account list was in the HTML that was opened.

## NPC website

screenshot restamp. A zip inside the RAR (about 42 MB, 217 entries) is the
same tree again.

`files/` is 163 small zips named for weapons and gadgets (bows,
bombs, banks, turrets, and similar). One opened pack (`bank.zip`) holds a

website. `graalfiles/` is a client download table: Gold, 1.1, 1.2.7, 1.2.8
beta 2, the 1.3 test, 1.3.1 through 1.3.9, 1.4, and a 2000 build, plus a
level-and-gif pack and a gif pack. The page's own notes call 1.2.8 beta 2
a well-known build and say attack points arrive in 1.3. The client zips
and a "graal movie" executable were not run. `help/` is five short
scripting pages: flags, signs, warps, a status picture, and making a
minimap. `dl.php` is a download script (it reads a line list and prints a
"missing information" error when the id is empty); it was not executed.
Two 2019 video files sit at the top of the archive and are not part of the
2003 tree.

## Chaos Continuum

20 KB, solid RAR. Twelve HTML pages and five GIFs. Page times run from
February 1999 to 23 November 1999, which matches the archive name.

Every real page is titled "CHAOS CONTINUUM" except a one-line joke page.
The shared menu is Downloads (levels, gifs/music, horses), Pics (maps,
towns, houses), and Other (credits, submit, vote, buy a house). The front
page says the site holds the files for playing there. Levels offer beta
packs from 0.2 through 0.9 and tell the reader to start at a named level.
Horses and town pictures are empty placeholders. Maps offers a planned map,
a real map, and a final map. Buying a house is priced at 1,000 rupees a
room. Credits name a main level creator. Gifs are a gate frame, a logo, and
a top banner.
