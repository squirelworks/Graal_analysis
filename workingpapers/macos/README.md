# macOS teardown workingpapers

macOS findings and lab state are kept in this folder, independently of Windows
and Linux. The current evidence establishes executable compatibility targets
and installation/debugger preparation; it does not establish a successful Graal run.

- [Client compatibility](client-compatibility.md): PowerPC v3–v5 and Intel v6.
- [Lab status and remaining tests](lab-status.md): Tiger recovery and the powered-off Lion VM.
- Sources `MAC-CLIENTS`, `TIGER-STATUS`, `TIGER-INSTALL`, `TIGER-GDB`, `LION-MEDIA`
  and `LION-CLIENT` in [the evidence index](../sources.tsv).

The owner's full macOS workingpapers have separate Tiger and Lion subfolders,
including the original logs, inventories and lab helpers. Those raw records
remain outside this public repository.
