**Graal Analysis 0.0.3** is the first edition of the **Graal Technical Reference Manual**: one 347-page PDF, `graal-trm-0.0.3.pdf`. It is built from commit b8643ec.

The 0.0.1 and 0.0.2 editions follow the notes. This one is organised by subject, the way a protocol RFC or a file-format spec is. Each fact appears once, with its evidence tag and the note it comes from.

## Contents

| Part | Subject |
| --- | --- |
| 0 | Conventions, notation and evidence tags |
| I | Client generations and builds |
| II | Wire protocol: framing, ciphers, login, every client and server message, props, file transfer, chat, UDP, the 6.11 protocol |
| III | File formats: levels, gmaps, GANI, object sets, tiles, sign text, saves, caches, config, assets |
| IV | Client behaviour by version: timing, movement, combat, death, items, HUD, sound, offline play, the editor |
| V–VII | Game servers, the listserver, RC and NC |
| VIII | NPC scripting: GS1 and GS2 |
| IX–X | Graal3D (2000) and the Torque-era 3D clients |
| XI | Tools and the formats they define |
| App. A–G | Message index, prop index, version matrix, glossary, open questions, source map, tag legend |

## Known gaps

This is not 1.0.0. A coverage audit found facts from six notes that are not yet in the manual. They are the 2.22 and 2.31 GS1 additions, the 2001 NPC-server commands, the buddy and list text requests, the GServer word filter, the `GSERVL01` level magic and 3.x class registration. They are added in the next edition, 0.0.4. The roadmap to 1.0.0 is in issue #191.

## Building it yourself

From a checkout of this tag: `python tools/manual/build_manual.py`. This needs pandoc and the `playwright` package; see `manual/README.md`.
