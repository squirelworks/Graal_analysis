**Graal Analysis 0.0.1** is the first published edition of the notes, as 18 PDFs (868 pages) grouped by subject. It is a reference to look things up in, not a book to read front to back. For that, read 0.0.2.

## What's in it

| PDF | Subject | Pages |
| --- | --- | ---: |
| `ch-00-contents.pdf` | Contents. Start here. | 2 |
| `ch-01-how-to-read.pdf` | How to read the notes: source tags, confidence, conventions | 14 |
| `ch-02-formats.pdf` | File formats: levels, ganis, images and more | 29 |
| `ch-03-protocol-part-1/2.pdf` | The client–server protocol | 107 |

| `ap-01` to `ap-04` | Appendices: recovered tools and trainers, game-asset inventories, server notes, NPC script names | 281 |

Every PDF is attached one by one, and all of them come in one archive, `graal-analysis-0.0.1-pdfs.tar.gz`. `release/0.0.1/README.md` in the tagged source describes what each PDF covers.

## Notes viewer

The notes viewer comes with the source, not as a separate download. From a checkout of this tag, run `python3 tools/navigator/navigator.py`. It serves the notes on loopback port 8765.

## How it was made

The PDFs are built from the markdown notes by `tools/release/build_book.py` (pandoc and weasyprint), and no PDF is over 100 pages. The tag points at the commit where the edition was finished, after the chapter 4 reading order (#187, #188).
