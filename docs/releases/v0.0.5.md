**Graal Analysis 0.0.5** is the third edition of the **Graal Technical Reference Manual**: one 290-page PDF, `graal-trm-0.0.5.pdf`. It is built from commit e1a54b0.

It adds the research published since 0.0.4. That research covers the late Linux clients (3.04, 4.04r2, 4.20r6, 6.01, 6.03), the exact 2.05 rev 2 GS1 readings, the unpacked Windows 6.1.1.3 image, the v7 inputs, and macOS archive identity. This edition also starts the move from stitched notes to a reasoned reference: five Parts now open with a reading synthesis, and the sections that had accreted one per finding are regrouped by topic.

The PDF reads differently from 0.0.4's. Tables no longer carry a Source column: every citation is a superscript number, and the closing Sources chapter lists each cited note once, linked to the repository. Without those columns the edition is 290 pages, against 0.0.4's 377 in the old layout. The PDF also has bookmarks for the first time, for every Part, chapter and section. The Markdown in the repository keeps each citation, with its evidence tag, on the line it supports.

## How coverage is checked

A new report, `tools/manual/coverage.py`, lists every distinctive term of a cited note that the manual does not contain, per Part. At this build the manual carries 71% of 11,600 terms from 374 cited notes. The weakest Parts are X (61%) and IX (62%). The report does not yet gate CI: carrying or explaining each miss is the 0.0.6 milestone in #191. `check_manual.py` and `check_carry.py` still gate every change.

## Known gaps

This is not 1.0.0. The roadmap is in #191, and the research toward 1.0.0 is tracked in #370. GS2 syntax and its standard library (E#207), the Torque-era frame loops (E#301), and the bytes a public 5.x or 6.x `Login` server sends (E#3) are still open.

## Building it yourself

From a checkout of this tag: `python tools/manual/build_manual.py --version 0.0.5`. This needs pandoc and the `playwright` and `pypdf` packages; see `manual/README.md`.
