**Graal Analysis 0.0.2** is the notes rewritten as **one reading**: five short chapters (45 pages). Read this first. Use 0.0.1 to look up the detail.

## Chapters

| PDF | Chapter | Pages |
| --- | --- | ---: |
| `00-how-to-read.pdf` | How to read this book: what the project is, what a source tag means, what is not claimed | 2 |
| `01-a-level-and-a-session.pdf` | A level and a session: how a level's tiles are stored, and what a client and server say in one session | 14 |
| `02-the-player.pdf` | The player: how the player's body and movement rules changed from 1998 to the first ganis in 2001 | 12 |
| `03-the-machines.pdf` | The machines: the listserver that answers first and the game server that answers second | 12 |
| `04-where-the-notes-disagree.pdf` | Where the notes disagree: bushes and walls, 1.39 knockback, listserver shapes and more | 5 |

Each PDF is attached on its own, and all five come in one archive, `graal-analysis-0.0.2-pdfs.tar.gz`. The source chapters are in `docs/book/` of the tagged source.

## Notes viewer

From a checkout of this tag, run `python3 tools/navigator/navigator.py`. It serves the notes on loopback port 8765.
