**Graal Analysis 0.0.9** is the seventh edition of the **Graal Technical Reference Manual**: one 415-page PDF, `graal-trm-0.0.9.pdf`, built from commit 40042bd. The same edition also comes as a print set for A4 printers, `graal-trm-0.0.9-print-a4.pdf`, with the §0.12 system map as an A3 insert in `graal-trm-0.0.9-a3-inserts.pdf`.

This edition is 0.0.8 with a correction. 0.0.7 and 0.0.8 named the private lab machines in their source list and in a few lab results. In this edition, and in the notes it cites, those machines are "lab host A" and "lab host B", and the lab notes that carried a machine name in their file name are renamed (`protocol/lab-appe-hosta-*`, `protocol/lab-appe-hostb-*`, `client-internals/static-reads-appendix-e-2026-11-20-hostb-final.md`). Nothing else in the manual changed. Use this edition in place of 0.0.7 and 0.0.8.

## Section numbers that changed

None. 0.0.9 has the same sections, in the same order and with the same numbers, as 0.0.8. App. E entry numbers (E#…) have not changed either.

No column of a citable data file changed. In `docs/gap-board.tsv`, the `where` column says "lab host A" or "lab host B" where it named a machine; the column itself is the same.

## What is new

| Where | Changed |
| --- | --- |
| Sources chapter | The renamed lab notes are listed under their new names |
| Parts I to XI, App. E | Citations of the renamed lab notes use their new names, and lab results say "lab host A" or "lab host B" in place of the machine names; the wording is otherwise unchanged |
| CI | A lab-detail leak check (`.github/scripts/check_lab_leaks.py`) fails on lab machine and VM names, personal home paths and image-relative code addresses, and reads the text of the PDFs in the tree for lab names |

## Known gaps

The same as 0.0.8. This is not 1.0.0. The roadmap is in #191, and the research toward 1.0.0 is tracked in #370. Research stays paused; `docs/gap-board.md` and `docs/experiments.md` list every open gap and the planned runs.

## Building it yourself

From a checkout of this tag: `python tools/manual/build_manual.py --version 0.0.9`. This needs pandoc and the `playwright` and `pypdf` packages; see `manual/README.md`.
