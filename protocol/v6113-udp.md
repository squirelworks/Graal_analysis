## Graal TCP

Three remotes are offered a Graal socket. Two are on port 14900 (three SYNs, one of them unanswered). One is on port 14882 (one SYN, answered). No UDP datagram in the file has one of those remotes as an end. Ports 14883, 14899, 14900 and 14901 do not occur as UDP ports.

Each answered session starts with the same clear prefix as `protocol/v6113-list-capture.md`. The client's first segment is the eight-byte token `GNP1905C`. The next segment begins `01 02 00 01 17 fd` and a zlib stream `78 9c`. That stream is 273 bytes on the wire and inflates to 262, and the inflated bytes begin `00 01 00 01 06 fc`. The same sizes on every answered session. The 256 bytes after that prefix are not recorded.

The server's first six bytes are `01 02 00 01`, then one marker byte, then `fd`.
